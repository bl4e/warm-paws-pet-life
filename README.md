# 暖爪宠物生活馆

这是一个面向宠物门店展示与预约的静态单页网站，适合用于展示洗护、美容、寄养与宠物用品等服务内容。

## 项目简介

“暖爪宠物生活馆” 是一个以社区宠物服务门店为原型设计的品牌展示网站，整体围绕“温暖、专业、可信赖”的服务体验展开。项目通过单页落地页的形式，集中呈现门店核心业务、环境氛围、商品陈列、到店信息与预约入口，方便用户了解门店展示内容并体验预约表单。当前是演示站，不接收真实预约。

本项目适合用作以下场景：

- 宠物门店官网展示页
- 宠物洗护 / 美容 / 寄养业务宣传页
- 社区生活服务类品牌落地页参考
- 静态网站部署与 GitHub Pages 演示项目

## 项目特点

- 单页静态站点，打开即可运行
- 中文品牌文案与门店场景展示
- 包含服务介绍、商品展示、到店信息与预约表单
- 适合部署到 GitHub Pages

## 当前可用范围

- 洗护、美容、寄养展示与切换可用，服务按钮会带入对应表单选项。
- 预约表单仅检查格式，不发送、不保存内容，不触发门店回访；刷新后内容丢失。
- 表单包含意向日期、时段及中国大陆手机号格式校验，日期以上海时区为准。
- 营业看板仅根据示例营业时间计算，不代表实际营业或预约余位。
- 地址、营业时间、评分、会员价格与权益均为演示资料；电话、微信、小红书及地图入口尚待真实资料确认。
- 主要本地图片使用 WebP，非首屏图片延迟加载；图标使用仓库内固定版本 Lucide 1.52.0。
- 洗护图片及会员猫咪图片仍依赖 Unsplash。旧 PNG 保留作为原始素材。

## 接通真实预约前

1. 确认真实门店地址、电话、地图链接、微信及服务价格，再替换示例文案和联系入口。
2. 配置外部表单服务或后端收单接口。GitHub Pages 只托管静态文件，不能自行存储预约。
3. 补充数据用途与隐私说明，在收单端校验内容，并处理发送中、失败重试和重复提交。
4. 仅在收单端确认成功后展示成功状态；意向时段仍需门店确认，不能视为已锁定档期。
5. 复核寄养入住与离店日期、疫苗要求及服务限制，根据实际业务补充字段。

## 手工验收

- 切换三项服务，检查标题、图片及预约服务自动带入；方向键、Home/End 可切换标签。
- 留空必填项、输入 `abc` 手机号或选择过去日期，应被阻止。
- 使用完整示例输入进行格式检查，提示必须明确未发送，且输入保持不变。
- 检查窄屏导航、锚点滚动、图片加载，以及无 JavaScript 时的演示说明。
- 检查所有 `assets/...` 路径在项目子目录部署下正常响应。
