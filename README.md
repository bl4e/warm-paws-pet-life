# 暖爪宠物生活馆

这是一个面向宠物门店展示与预约的静态单页网站，适合用于展示洗护、美容、寄养与宠物用品等服务内容。

## 项目特点

- 单页静态站点，打开即可运行
- 中文品牌文案与门店场景展示
- 包含服务介绍、商品展示、到店信息与预约表单
- 适合部署到 GitHub Pages

## 项目结构

```text
.
├─ AGENTS.md
├─ README.md
├─ index.html
└─ assets/
```

## 本地预览

在项目根目录运行：

```powershell
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000/
```

## 部署说明

本项目为纯静态站点，可直接部署到 GitHub Pages，无需构建步骤。
