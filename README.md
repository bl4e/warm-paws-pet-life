# 暖爪宠物生活馆

这是一个面向宠物门店展示与预约的静态单页网站，适合用于展示洗护、美容、寄养与宠物用品等服务内容。

## 项目简介

“暖爪宠物生活馆” 是一个以社区宠物服务门店为原型设计的品牌展示网站，整体围绕“温暖、专业、可信赖”的服务体验展开。项目通过单页落地页的形式，集中呈现门店核心业务、环境氛围、商品陈列、到店信息与预约入口，方便用户快速了解门店特色并完成咨询或预约。

本项目适合用作以下场景：

- 宠物门店官网展示页
- 宠物洗护 / 美容 / 寄养业务宣传页
- 社区生活服务类品牌落地页参考
- 静态网站部署与 GitHub Pages 演示项目

## 项目特点

- 单页静态站点，打开即可运行
- 中文品牌文案与门店场景展示
- 包含服务介绍、商品展示、到店信息与预约表单
- 适合部署到 GitHub Pages

## 项目结构

```text
.
├─ AGENTS.md

```

## 本地预览

在项目根目录运行：

```powershell
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000/
```
